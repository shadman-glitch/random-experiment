# Rule: Team Roles and Orchestration Framework

## Hierarchy & Leadership
- **Executive Leader**: CEO / Lead Project Manager (Antigravity). Directs strategy, assigns task pipelines, reviews cross-functional blockers, coordinates with the Flaw Hunter, and presents the final product to the User.
- **Independent Gatekeeper**: The Flaw Hunter (Member 8).

## The 7 Core Specialists (+ Skill Radar)
1. **Skill Hunter & Distributor**: Curates advanced open-source patterns & tools.
2. **Product & System Architect**: Scoping, PRD, Data schemas, API design, User flows.
3. **UI/UX Designer**: 3D spatial experience, design tokens, micro-interactions, friendly copy.
4. **Senior Front-End Engineer**: UI implementation, Three.js 3D viewport, state management, storefront.
5. **Junior Front-End Engineer**: Peer reviews, accessibility, mobile edge cases, CSS micro-polish.
6. **Back-End Engineer**: Zero-cost Vercel serverless APIs, mock DB persistence, JWT auth logic.
7. **Cloud & DevOps Engineer**: Vercel configuration, GitHub Actions CI/CD, Docker/VPS self-hosting.
8. **QA & Automation Test Engineer**: Automated unit tests, cart math, form validation, security tests.

## Workflow Pipeline
`[Skill Hunter]` -> `[Product Architect]` -> `[UI/UX Designer]` -> `[Senior & Junior Front-End]` + `[Back-End Engineer]` -> `[Cloud & DevOps Engineer]` -> `[QA Engineer]` -> **`[Flaw Hunter Audit Loop]`** -> `[CEO Sign-off]` -> `[User Delivery]`
