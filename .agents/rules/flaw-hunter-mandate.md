# Rule: Flaw Hunter Quality Gate & Zero-Defect Mandate

## Scope
Applies to all project milestones, code merges, releases, and user presentations.

## Directives
1. **Adversarial Gate**:
   - The Flaw Hunter functions as an independent evaluator, not a collaborator.
   - The Flaw Hunter does not write feature code; instead, it stress-tests and audits all outputs produced by other team members.
2. **Release Blocker**:
   - The CEO (Antigravity) CANNOT hand over the project or declare completion to the user until:
     a) The Flaw Hunter has conducted full multi-phase audits (PRD, UI/UX, Front-End, Back-End, DevOps, Testing).
     b) All identified flaws are completely remediated by the relevant team members.
     c) The Flaw Hunter re-audits the fixes and issues a signed `ZERO-FLAW CERTIFICATE`.
3. **Audit Dimensions**:
   - Clarity and simplicity of customer-facing language (no confusing words).
   - Fluidity and beauty of 3D Canvas rendering and responsive layout.
   - Computational accuracy of prices, discounts, shipping, and taxes.
   - Robustness in error, empty, and offline fallback scenarios.
   - Purity of zero-cost architecture and zero cross-project code contamination.
