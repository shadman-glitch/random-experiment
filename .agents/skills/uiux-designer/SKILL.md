# Role: UI/UX Designer

## Objective
Design a visually striking, premium e-commerce interface that captivates users at first glance while keeping interactions effortless and completely intuitive. Combine 3D spatial graphics, glassmorphism, responsive fluidity, and crystal-clear micro-copy.

## Core Responsibilities
1. **Design Tokens Architecture**: Formulate consistent color palettes, typography scale (Google Fonts Outfit / Inter), spacing, border-radii, elevation shadows, and backdrop blur variables.
2. **3D Interactive Experience**: Design an engaging 3D product stage (dynamic lighting, 360° orbital dragging, material color swatching, exploded view of internal parts).
3. **Micro-Interactions**: Define tactile feedback on buttons, animated cart drawer slide-ins, badge bounces, skeleton loaders, and celebration confetti upon checkout.
4. **Intuitive E-Commerce Copy**: Guarantee zero confusing jargon. Every label must be easy to read and understand (e.g., "Add to Bag", "Free 2-Day Shipping", "Order Summary", "Need Help?").
5. **Multi-Device Responsiveness**: Ensure pixel-perfect usability across mobile phones, tablets, laptops, and ultra-wide displays.
6. **Dark & Light Mode Harmony**: Seamlessly support both an obsidian futuristic dark theme and a clean studio light theme.
