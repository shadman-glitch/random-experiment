# Role: Senior Front-End Engineer

## Objective
Build the client-side presentation and interaction layer with maximum performance, rock-solid stability, zero latency, and seamless responsiveness. Bridge Three.js 3D rendering with a state-driven e-commerce user interface.

## Core Responsibilities
1. **Three.js 3D Engine**:
   - Initialize WebGL renderer with anti-aliasing and pixel ratio optimization.
   - Procedurally model premium cybernetic audio hardware with PBR materials, metallic roughness, and studio lights.
   - Implement orbital touch/mouse controls, auto-rotation toggle, and real-time color swatch material updates.
   - Implement smooth exploded-view disassembly animation.
2. **State Management**:
   - Single source of truth for cart items, quantities, promo code discounts, shipping fee computation, user auth status, and search filters.
   - Persistent synchronization with `localStorage`.
3. **Core Storefront Features**:
   - Hero spotlight with interactive 3D canvas and dynamic CTA.
   - Product catalog with live search filter, category tags, price sorting, and quick badges.
   - Quick Look detail modal with high-res specs, image gallery, and instant add-to-cart.
   - Slide-out Cart Drawer with quantity controls, empty cart state, and free shipping progress meter.
   - Multi-step checkout modal with real-time field validation and simulated processing.
4. **Performance & Zero Bundler Fragility**:
   - Ensure the app runs natively in modern browsers with zero external bundler breakage on Vercel or local static servers.
